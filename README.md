# 🏠 Real-Pro

A modern **Real Estate & E-Commerce web application** built with **Python and Django**.

## ✨ Features

* 🏡 Real estate property listings & details
* 👨‍💼 Real estate agents
* 🛒 E-commerce shop & shopping cart
* 🎟️ Coupon & discount system
* 📦 Checkout & order management
* 🔐 User registration & authentication
* 📝 Blog
* 📩 Contact form
* ⚙️ Django Admin Panel
* 📱 Responsive UI

## 🛠️ Tech Stack

* Python
* Django
* HTML5 / CSS3
* JavaScript
* SQLite / PostgreSQL
* Gunicorn
* Render

## 🚀 Run Locally

```bash
git clone https://github.com/navidkmp/Real-Pro.git
cd Real-Pro

python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt
python manage.py migrate
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```
